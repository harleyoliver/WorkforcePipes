# WorkforcePipes: Enterprise Power Platform Solution

This repository contains a professional-grade Power Platform solution designed for high-scale workforce integration. It demonstrates a **Pro-Code approach** to low-code development, utilizing modern web standards (React/Tailwind) and automated deployment pipelines.

## 🚀 Project Overview
* **Architecture:** Hybrid Low-Code/Pro-Code with Microsoft Dataverse.
* **Frontend:** Custom React-based PCF (PowerApps Component Framework) controls styled with Tailwind CSS.
* **Integration:** Azure Logic Apps and Power Automate middleware for bridging legacy CMS (Squiz/WordPress) data.
* **DevOps:** Managed via Power Platform CLI (PAC) with GitHub Actions for automated solution packaging and environment deployment.

## 🛠 Tech Stack
- **Platform:** Microsoft Power Platform (Dataverse, Power Apps, Power Automate)
- **Code:** TypeScript, React, Tailwind CSS
- **Tools:** PAC CLI, Node.js, Linux Environment
- **ALM:** Git-based version control for solution metadata (.cdsproj)

## 📁 Repository Structure
- `/src`: Custom PCF components and web resources.
- `/solutions`: Unpacked Power Platform solution metadata.
- `/.github/workflows`: CI/CD pipelines.
